它到底做了什么

三件事，把"看着还行"变成"可以交付"。

从种子起笔

每个模板自带 assets/template.html：六个 token 变量、8 点间距、920px 回流都已经写好。你要做的只是把版式骨架贴进去、换成真实文案。

绑定真实 token

设计系统目录里每个品牌都带编译好的 tokens.css。颜色、字体、间距是可读的值，不是"我印象里的那种紫"。

交付前过闸门

references/checklist.md 把主观判断拆成可判定的条目：裸 hex、强调色超预算、编造指标、emoji 当图标，一条都过不去。

接上桥之前与之后

差的不是模型，是有没有可对照的契约。

环节 直接让模型写 接上设计桥
起笔空白文件，边写边定结构种子模板 + 8 种现成版式骨架
配色凭记忆猜，容易滑向通用紫读 tokens.css 的真实值
强调色每屏五六处，重点消失每屏最多两处，逐屏可数
排版系统无衬线当标题衬线标题 + 等宽数字
指标顺手写出"快 10 倍"必须有来源，否则留可辨认的占位
交付 还得再修一轮样式 自包含 HTML，打开即用
